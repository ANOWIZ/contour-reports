# Контур — квартальная отчётность

Веб-приложение для продуктовых команд. Продуктовый лид заполняет отчёт за квартал, руководство видит показатели направлений, отклонения от плана и риски.

Прототип для возможного внедрения в компании. Публичная копия содержит исходники и демонстрационные данные. Рабочие отчёты, документы, настройки сервера и исходный шаблон презентации не публикуются.

## Что реализовано

- Раздельный доступ для продуктового лида и руководства.
- Плановые и фактические показатели, расчёт отклонений, конверсий и полноты отчёта.
- Черновик, отправка на проверку, возврат и публикация отчёта.
- История версий и контроль целостности отправленного отчёта.
- Сводка по продуктам, графики и перенос данных между кварталами.
- Серверный модуль генерации PowerPoint; для запуска экспорта нужен отдельный шаблон и соответствующий манифест.

Стек: Next.js 16, React 19, TypeScript, PostgreSQL, Drizzle, Better Auth, Recharts, PptxGenJS.

## Локальный запуск

Нужны Node.js 22 и Docker.

```powershell
npm ci
Copy-Item .env.example .env.local
docker compose up -d
npm run db:migrate
npm run db:seed
npm run dev
```

Перед запуском замените `BETTER_AUTH_SECRET` в `.env.local` случайной строкой. База из Docker Compose слушает порт 5433. Данные seed — учебные; запускайте его только на отдельной демонстрационной базе.

Откройте `http://localhost:3000`. Демо-аккаунты: `lead@contour.local` и `management@contour.local`, пароль обоих — `demo-report`. Это тестовые учётные записи, не доступ к рабочей системе.

## Проверки

```powershell
npm test
npm run lint
npx tsc --noEmit
npm run build
```

Интеграционный тест требует отдельной PostgreSQL-базы: `RUN_DB_INTEGRATION=1 npm run test:integration` (для PowerShell задайте переменную через `$env:RUN_DB_INTEGRATION = '1'`). Браузерные тесты запускаются командой `npm run test:e2e` и также требуют подготовленной базы.

## Ограничения публичной версии

Шаблон PowerPoint и его манифест исключены из публикации. Поэтому кнопка экспорта не создаёт презентацию без дополнительной настройки `REPORT_PPTX_TEMPLATE_PATH` и `PPTX_TEMPLATE_MANIFEST_PATH`. Модуль проверяет соответствие SHA-256 шаблона манифесту. Учебные данные не отражают показатели реальных компаний. Развёртывание в production требует собственных настроек доступа и базы.
